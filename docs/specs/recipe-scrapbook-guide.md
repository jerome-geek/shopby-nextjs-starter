# [기획서] 레시피 스크랩북(컬렉션) 가이드

본 문서는 사용자가 마음에 드는 레시피를 저장하고 나만의 폴더로 분류하여 편리하게 관리할 수 있는 '스크랩북' 페이지의 사용성을 정의합니다.

## 1. 개요
스크랩북은 사용자가 관심 있는 레시피를 개인별 '컬렉션'이라는 폴더 단위로 그룹화하여 관리할 수 있는 개인 맞춤형 공간입니다.

- **접근 권한**: **회원 전용** (로그인한 사용자만 본인의 스크랩북을 이용할 수 있습니다.)

## 2. 주요 기능 및 사용성

### 2.1 직관적인 화면 구성
- **상단 (내 폴더 관리)**: 사용자가 만든 모든 레시피 폴더(컬렉션)가 가로 탭 형태로 나열됩니다.
    - `전체` 탭을 통해 모든 폴더의 레시피를 한꺼번에 볼 수 있습니다.
    - `+` 버튼으로 언제든지 새로운 폴더를 추가하여 레시피를 분류할 수 있습니다.
- **하단 (레시피 목록)**: 선택한 폴더에 담긴 레시피들이 보기 편한 리스트 형태로 나타납니다.
    - **내가 만든 레시피**: 직접 등록한 나만의 요리법
    - **스크랩한 레시피**: 다른 사람의 요리법 중 '스크랩' 버튼으로 저장해둔 요리법

### 2.2 편리한 탐색 경험
- **폴더별 필터링**: 복잡한 검색 없이 탭 클릭 한 번으로 원하는 테마(예: 다이어트, 술안주 등)의 레시피만 모아볼 수 있습니다.
- **끊김 없는 이동**: 폴더를 전환해도 화면 깜빡임 없이 부드럽게 리스트가 변경되어 쾌적한 탐색이 가능합니다.
- **상태 유지**: 특정 폴더를 보다가 뒤로가기를 하거나 페이지를 다시 방문해도 보던 상태가 유지되어 편리합니다.

### 2.3 기기별 최적화 (반응형)
- **PC**: 넓은 화면에서 많은 수의 폴더와 레시피를 한눈에 시원하게 확인할 수 있습니다.
- **모바일**: 손가락으로 가볍게 밀어서 폴더를 선택할 수 있는 가로 스크롤 방식의 탭을 제공하여 한 손으로도 쉽게 조작할 수 있습니다.

---

## 3. 사용자 이용 시나리오
1.  **발견**: 다른 사람의 맛있는 레시피를 발견하면 상세 페이지에서 '스크랩'을 누릅니다.
2.  **분류**: 기존에 만들어둔 폴더에 저장하거나, 필요하다면 즉시 새 폴더(예: '이번 주말 요리')를 만들어 저장합니다.
3.  **활용**: 요리 직전 스크랩북에 들어가 저장해둔 레시피를 꺼내어 바로 조리 단계에 집중합니다.
