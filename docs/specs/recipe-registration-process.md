# [기획서] 레시피 등록 프로세스 가이드

본 문서는 JollyPot 플랫폼의 핵심 기능인 레시피 등록 서비스의 두 가지 방식(AI 자동 등록 및 수동 등록)에 대한 기술 및 운영 프로세스를 정의합니다.

## 1. AI 자동 등록 방식 (SNS URL 연동)
외부 웹페이지 및 SNS의 레시피 정보를 AI가 분석하여 자동으로 등록하는 스마트 프로세스입니다.

### 1.1 프로세스 흐름
1.  **URL 입력**: 사용자가 레시피가 포함된 외부 웹사이트(블로그, 뉴스, SNS 등)의 URL을 입력합니다.
2.  **AI 분석 및 스크래핑**: 시스템 백엔드에서 해당 URL의 콘텐츠를 분석하여 요리명, 재료, 조리 순서, 이미지 등을 추출합니다.
3.  **임시 레시피 생성**: 추출된 데이터를 기반으로 시스템 내에 임시 레시피 객체를 생성합니다.
4.  **사용자 확인 및 저장**: 분석 완료 후 사용자에게 결과를 보여주며, 사용자가 최종 확인을 거쳐 저장하면 등록이 완료됩니다.

### 1.2 주요 특징
- **편의성**: 복잡한 텍스트 입력 없이 URL 하나로 레시피 등록 가능
- **정확도**: 이미지와 텍스트를 매칭하여 최적화된 조리 단계 구성
- **중복 검사**: 이미 등록된 URL인 경우 중복 알림을 통해 데이터 무결성 유지

---

## 2. 수동 이미지 등록 방식 (직접 등록)
사용자가 보유한 조리 과정 사진을 바탕으로 직접 내용을 입력하는 정밀 등록 프로세스입니다.

### 2.1 프로세스 흐름
1.  **이미지 선 업로드 (Step 1)**:
    *   조리 과정 사진들을 다중 선택하여 업로드합니다.
    *   시스템은 각 이미지에 고유 번호(SNO)를 발급하여 임시 저장합니다.
2.  **레시피 정보 입력 (Step 2)**:
    *   요리 제목, 간단 소개, 요리 시간, 인분, 칼로리 등 기본 정보를 입력합니다.
    *   요리에 필요한 재료와 분량을 리스트 형태로 작성합니다.
3.  **조리 단계 매칭 (Step 3)**:
    *   업로드된 이미지 순서에 맞춰 각 단계별 설명(Description)을 작성합니다.
    *   드래그 앤 드롭을 통해 이미지 순서를 자유롭게 변경할 수 있으며, 이에 따라 단계 번호가 실시간으로 재구성됩니다.
4.  **최종 등록 (Step 4)**:
    *   대표 이미지를 선정하고 최종 등록 버튼을 클릭합니다.
    *   입력된 텍스트와 이미지 번호(SNO)가 결합되어 정식 레시피로 발간됩니다.

### 2.2 주요 특징
- **실시간 동기화**: 이미지 순서 변경 시 조리 단계 텍스트와 자동으로 매칭되어 편집 오류 방지
- **임시 저장 안정성**: 이미지 업로드와 텍스트 입력을 분리 처리하여 대용량 데이터 전송 시 안정성 확보
- **유연한 편집**: 조리 단계의 추가, 삭제, 위치 변경이 자유로운 UI 제공

## 3. 요약 비교

| 항목 | AI 자동 등록 | 수동 이미지 등록 |
| :--- | :--- | :--- |
| **입력 방식** | 외부 URL 입력 | 직접 이미지 업로드 및 텍스트 작성 |
| **데이터 추출** | AI 알고리즘에 의한 자동 추출 | 사용자가 직접 정의 및 입력 |
| **권장 타겟** | 외부 레시피를 빠르게 스크랩하려는 사용자 | 본인만의 시그니처 레시피를 상세히 기록하려는 사용자 |
| **주요 기술** | AI 분석 엔진, URL 스크래퍼 | 이미지 임시 저장소(Zustand), 실시간 상태 동기화 |
